📝 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:
═════════════════════════════════════════════════════════════

### CLI - Просто и понятно

```bash
# Получить НОТЫ в MusicXML (откроется в MuseScore)
bonk convert song.mp3 song.musicxml

# Получить уже готовый PDF с нотами для печати
bonk convert audio.wav score.pdf

# Дефолт - MIDI для DAW
bonk convert voice.wav output.mid
```

### Python код

```python
from bonk import AudioToMidiConverter

converter = AudioToMidiConverter()

# Вариант 1: MIDI файл
converter.convert('song.mp3', 'output.mid', format='midi')

# Вариант 2: MusicXML - НОТЫ! (откроется в MuseScore)
converter.convert('song.mp3', 'output.musicxml', format='musicxml')

# Вариант 3: PDF - готово к печати
converter.convert('song.mp3', 'output.pdf', format='pdf')
```

═════════════════════════════════════════════════════════════

🎯 РАЗЛИЧИЕ ФОРМАТОВ:
═════════════════════════════════════════════════════════════

MIDI (.mid)
├─ Для DAW (Ableton, FL Studio, Cubase)
├─ Для синтезаторов и MIDI клавиатур
├─ Просто последовательность нот
└─ Не подходит для чтения партитуры

MusicXML (.musicxml)
├─ НОТЫ на нотном стане!
├─ Откроется в MuseScore, Finale, Sibelius
├─ Можно редактировать в раскладке
├─ Стандартный формат музыкальной индустрии
└─ РЕКОМЕНДУЕТСЯ для видения нот

PDF (.pdf)
├─ Готовая к печати партитура
├─ Красиво выглядит
├─ Можно раздать музыкантам
├─ Не редактируется
└─ РЕКОМЕНДУЕТСЯ для чтения с листа

═════════════════════════════════════════════════════════════

🎼 КАК ИСПОЛЬЗОВАТЬ MUSICXML:
═════════════════════════════════════════════════════════════

1. Преобразуйте аудио в MusicXML:
   bonk convert song.mp3 score.musicxml

2. Откройте в MuseScore (бесплатно):
   https://musescore.org/

3. Видите ноты на нотном стане!
   ♪ ♫ ♬ ♭ ♮ ♯

4. Можете:
   - Редактировать ноты
   - Менять инструменты
   - Добавить текст и аккорды
   - Экспортировать в PDF, MP3, MIDI и т.д.

═════════════════════════════════════════════════════════════

🖨️ КАК ИСПОЛЬЗОВАТЬ PDF:
═════════════════════════════════════════════════════════════

1. Преобразуйте аудио в PDF:
   bonk convert song.mp3 score.pdf

2. Откройте PDF и распечатайте

3. Возьмите в руки и читайте с листа!
   (Если вещество расскажет как 😄)

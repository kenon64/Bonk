🎉 BONK - Сборка обновлена!
==================================

✨ НОВЫЕ ВОЗМОЖНОСТИ СБОРКИ
═════════════════════════════

Теперь проект включает полностью автоматизированные скрипты для:
✅ Установки всех зависимостей
✅ Компиляции в однофайловый exe/исполняемый файл
✅ Создания независимого приложения без Python

📦 НОВЫЕ ФАЙЛЫ
════════════════

1. setup-and-build.bat
   • Автоматический скрипт для Windows
   • Двойной клик или запуск из CMD
   • Проверяет Python, устанавливает всё, компилирует exe

2. setup-and-build.sh
   • Автоматический скрипт для Linux/macOS
   • Создаёт виртуальное окружение
   • Устанавливает зависимости и компилирует

3. bonk.spec
   • PyInstaller конфигурация
   • Определяет как упаковать приложение
   • Указывает скрытые импорты и зависимости

4. BUILD_INSTRUCTIONS.md
   • Полная документация по сборке
   • Решение проблем
   • Примеры использования

5. requirements.txt (обновлен)
   • Добавлен pyinstaller>=6.0.0
   • Все остальные зависимости как было

🚀 БЫСТРЫЙ СТАРТ
══════════════════

WINDOWS:
--------
1. Откройте CMD/PowerShell в папке проекта
2. Запустите: setup-and-build.bat
3. Ждите 5-10 минут
4. Найдите exe: dist/bonk.exe

LINUX / macOS:
--------------
1. Откройте терминал в папке проекта
2. Запустите: ./setup-and-build.sh
3. Ждите 5-10 минут
4. Найдите файл: dist/bonk

💻 ЧТО ДЕЛАЮТ СКРИПТЫ
══════════════════════

setup-and-build.bat / setup-and-build.sh:

Шаг 1: Проверка Python
   ✓ Проверяет наличие Python 3.8+
   ✓ Если не установлен - показывает ошибку с ссылкой

Шаг 2: Виртуальное окружение (только Linux/macOS)
   ✓ Создаёт venv если не существует
   ✓ Активирует его

Шаг 3: Обновление pip
   ✓ Устанавливает последние версии инструментов

Шаг 4: Установка зависимостей
   ✓ pip install -r requirements.txt
   ✓ Установит librosa, numpy, scipy, click, pyinstaller
   ✓ Время: 2-3 минуты

Шаг 5: Проверка PyInstaller
   ✓ Убеждается что PyInstaller установлен

Шаг 6: Компиляция в exe
   ✓ pyinstaller bonk.spec
   ✓ Создаёт однофайловый exe/исполняемый файл
   ✓ Время: 2-5 минут

⚙️ ТЕХНИЧЕСКИЕ ДЕТАЛИ
══════════════════════

PyInstaller:
   • Анализирует Python код
   • Находит все импорты и зависимости
   • Упаковывает в exe/исполняемый файл

bonk.spec:
   • Конфиг файл для PyInstaller
   • Определяет hiddenimports (librosa, scipy, etc.)
   • Исключает ненужные модули (matplotlib, pandas)

Размер файла:
   • exe: 150-200 МБ (однофайловый)
   • Может быть уменьшен использованием --onedir

🔧 КАСТОМИЗАЦИЯ
═════════════════

Если нужны изменения, отредактируйте bonk.spec:

Изменить имя:
   name='bonk' → name='MyApp'

Консоль vs GUI:
   console=True → console=False  (для GUI приложений)

Добавить иконку:
   Добавьте: icon='path/to/icon.ico'

Изменить путь вывода:
   --distpath ./dist →  --distpath .

Если что-то не работает:

1. Проверьте BUILD_INSTRUCTIONS.md (раздел "Проблемы и решения")
2. Убедитесь что Python установлен и в PATH
3. Обновите pip: python -m pip install --upgrade pip
4. Переустановите PyInstaller: pip install --upgrade pyinstaller

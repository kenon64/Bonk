# Примеры

В этой папке содержатся примеры использования Bonk.

## Содержимое

### Папки
- **audio/** - примеры аудиофайлов для преобразования
- **output/** - результаты преобразования (MIDI файлы)

## Использование

### Базовый пример
```bash
cd ..
bonk convert audio/example.wav output/example.mid
```

### С параметрами
```bash
bonk convert audio/song.mp3 output/song.mid --tempo 140 --min-duration 0.1
```

## Примеры аудиофайлов

Вы можете использовать:
- Записи вокала
- Соло инструментов (гитара, пиано, флейта и т.д.)
- Простые мелодии

Примеры лучше всего работают с монофоническим звуком (один голос/инструмент).

## Создание примера

1. Поместите аудиофайл в папку `audio/`
2. Запустите конвертер
3. Результат появится в `output/`

Поддерживаемые форматы: MP3, WAV, OGG, FLAC

# Участие в развитии Bonk

Спасибо за интерес к проекту! Мы приветствуем участие сообщества.

## Как начать

### Форк и клон
```bash
# Форк репозитория на GitHub
# Затем клонируйте ваш форк
git clone https://github.com/YOUR_USERNAME/Bonk.git
cd Bonk
```

### Виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install pytest black flake8 mypy
```

### Создайте ветку для вашего улучшения
```bash
git checkout -b feature/your-feature-name
# или для исправления бага
git checkout -b bugfix/your-bugfix-name
```

## Разработка

### Стиль кода
Мы используем:
- **Black** для форматирования
- **Flake8** для проверки стиля
- **MyPy** для проверки типов

```bash
# Форматировать код
black bonk/

# Проверить стиль
flake8 bonk/

# Проверить типы
mypy bonk/
```

### Тестирование
```bash
# Запустить тесты
pytest tests/ -v

# С покрытием
pytest tests/ --cov=bonk
```

### Добавление новых функций
1. Создайте тесты в `tests/`
2. Реализуйте функцию
3. Обновите документацию
4. Убедитесь, что все тесты проходят

## Коммиты

Используйте понятные сообщения коммитов:
```
feat: добавить поддержку MusicXML
fix: исправить обнаружение высоты для низких частот
docs: обновить README с примерами
test: добавить тесты для PitchDetector
```

## Pull Request

1. Убедитесь, что ваш код следует стилю проекта
2. Добавьте тесты для новых функций
3. Обновите документацию
4. Напишите понятное описание PR

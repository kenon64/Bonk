# 🪟 Инструкция установки на Windows

Если вы получаете ошибку **"Python не найден"** или **"Build не является внутренней или внешней командой"**, следуйте этой инструкции.

## ❌ Первая попытка не удалась?

Вероятные причины:
1. **Python не установлен** 
2. **Python не добавлен в PATH** (самая частая причина!)
3. **Компьютер не был перезагружен** после установки Python

## ✅ Решение

### Шаг 1: Установка Python

1. Перейдите на сайт https://www.python.org
2. Нажмите **"Downloads"** → **"Windows"**
3. Скачайте **Python 3.11** или 3.12 (рекомендуется)
4. Запустите установщик (.exe файл)

### ⚠️ ВАЖНО: Первый экран установки

**ОБЯЗАТЕЛЬНО установите галочку:**

```
✓ Add Python to PATH
```

Это критически важно! Без этого Windows не сможет найти Python.

Выглядит так:
```
[✓] Add Python 3.11 to PATH        ← ГАЛОЧКА ДОЛЖНА БЫТЬ!
[ ] Install for all users
[ ] Associate files with Python
[ ] Create shortcuts for installed extensions
```

### Шаг 2: Завершение установки

1. Нажмите "Install Now"
2. Дождитесь завершения установки
3. **ПЕРЕЗАГРУЗИТЕ КОМПЬЮТЕР!** (это важно!)

### Шаг 3: Проверка установки

1. Откройте **Command Prompt** (cmd.exe) - нажмите `Win + R`, введите `cmd`, нажмите Enter
2. Введите команду:
   ```
   python --version
   ```
3. В ответ должны увидеть что-то вроде:
   ```
   Python 3.11.7
   ```

Если вы **видите номер версии** - Python установлен правильно! ✓

Если вы видите **"python is not recognized"** - значит PATH не обновлён. Перезагрузитесь ещё раз.

### Шаг 4: Запуск скрипта сборки

1. Откройте Command Prompt в папке Bonk
2. Запустите скрипт:
   ```
   setup-and-build.bat
   ```

## 🔧 Если всё ещё не работает

### Попробуйте установить Python через Microsoft Store

Microsoft Store часто проще:

1. Откройте Microsoft Store
2. Найдите "Python 3.11" или "Python 3.12"
3. Нажмите "Установить"
4. Перезагрузитесь

### Альтернатива: Установка через Chocolatey

Если у вас установлен Chocolatey:

```
choco install python
```

Затем перезагрузитесь.

### Если ничего не помогает

1. Удалите старую версию Python (Параметры → Приложения → Приложения и функции)
2. Перезагрузитесь
3. Установите Python ещё раз, **старайтесь выбирать параметры по умолчанию**
4. Не забудьте галочку "Add Python to PATH"
5. Перезагрузитесь

## 📝 Проверка PATH вручную

Если Python установлен, но всё равно не работает, можно добавить Python в PATH вручную:

1. Нажмите `Win + X` → "Параметры"
2. "Система" → "О системе" → "Дополнительные параметры системы"
3. "Переменные среды..."
4. Нажмите "Создать" и добавьте переменную:
   - **Имя**: `PYTHON_PATH`
   - **Значение**: путь к python.exe, например: `C:\Users\YourName\AppData\Local\Programs\Python\Python311`

5. Нажмите OK на всех окнах
6. Перезагрузитесь

## 🎉 Успешная установка

Если вы видели "Python 3.X.X" после команды `python --version` - вы готовы!

Запустите:
```
setup-and-build.bat
```

И ждите завершения сборки (может занять 3-5 минут).

## ✨ Результат

Если всё прошло успешно, вы увидите сообщение:

```
✅ УСПЕШНО!

📦 exe-файл создан: dist\bonk.exe

🚀 Вы можете запустить bonk.exe напрямую без установки Python!
```

Теперь можете использовать `bonk.exe` на любом компьютере без Python!

## 📞 Если есть вопросы

- Проверьте что Python действительно установлен: `python --version`
- Убедитесь что вы в папке проекта Bonk
- Попробуйте переустановить Python с галочкой "Add Python to PATH"
- Всегда перезагружайтесь после установки!
